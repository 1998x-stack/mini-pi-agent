# v0.2 — Streaming Protocol + Tool Scheduler

Status: active design / implementation branch.

Canonical detail lives in root `version.md`; this file is the compact architectural map.

## Core lesson

v0.1 proves the feedback loop. v0.2 proves that the same semantics can survive asynchronous transport and concurrent execution.

```text
provider chunks
      ↓
AssistantStreamAssembler
      ↓
AssistantMessage
      ↓
ToolScheduler
 ├── SequentialScheduler
 └── ParallelScheduler
      ↓
ordered ToolResultMessage[]
```

The most important distinction is:

> A `Tool` defines how one invocation executes. A `ToolScheduler` defines how multiple invocations are coordinated.

## Required mechanisms

- canonical stream/chunk abstraction
- real OpenAI-compatible SSE path
- fragmented text/tool-call assembly
- deterministic malformed-stream errors
- `ToolScheduler` interface
- sequential reference scheduler
- conservative parallel scheduler
- external scheduling policy rather than concurrency logic inside `Tool`
- deterministic result ordering
- run cancellation propagation
- per-tool timeout
- structured trace recorder
- event partial-order tests

## Conservative concurrency

Default to exclusive execution unless a policy explicitly declares a tool call safe to overlap.

Initial educational policy:

```text
read   → parallel
write  → exclusive
edit   → exclusive
shell  → exclusive
custom → exclusive by default
```

Parallel completion order must never change the order of observations returned to the model.

## New source boundaries

```text
src/llm/streaming/
  sse-parser.ts
  assistant-stream-assembler.ts

src/scheduler/
  types.ts
  policy.ts
  sequential-scheduler.ts
  parallel-scheduler.ts

src/tracing/
  trace-recorder.ts
```

`runAgentLoop()` orchestrates these components but must not own SSE parsing, fragmented JSON assembly, batching algorithms, timeout internals, or trace storage.

## Explicit non-goals

Do not add in v0.2:

- context compaction
- Skills
- extensions/hooks
- MCP
- session branching
- permission/sandbox UI
- arbitrary DAG scheduling
- distributed scheduling
